# 咖啡知识百科全书

一个纯静态的中文咖啡知识百科网站：从一颗豆子到一杯咖啡，系统收录咖啡历史、豆种、产地、烘焙、研磨、冲煮、饮品、文化、健康与术语，共 **59 个词条**、**10 大分类**，支持全文搜索与分类浏览。

## 功能

- 首页：Hero 展示、搜索框、分类卡片、精选词条
- 分类浏览：10 大分类的词条列表
- 词条详情：标题、摘要、多段正文、相关词条推荐
- 全文搜索：标题、摘要、正文统一检索，关键词高亮
- 响应式设计：桌面与手机均可舒适阅读
- 哈希路由（`#/`、`#/cat/xxx`、`#/entry/xxx`），无需服务器即可工作

## 文件结构

```
coffee-wiki/
├── index.html            # 单页应用骨架（页眉搜索 + 分类导航 + 内容容器）
├── assets/
│   ├── css/

```

## 本地预览

无需安装任何依赖，直接用浏览器打开 `index.html` 即可（支持 `file://` 协议）。

也可以起一个本地静态服务器（任选其一）：

```bash
# Python
python3 -m http.server 8000
# 然后访问 http://localhost:8000

# Node
npx serve .
```

## 发布到 GitHub Pages

1. 在 GitHub 新建仓库（例如 `coffee-wiki`），把本目录所有文件推上去
2. 进入仓库的 **Settings → Pages**
3. Source 选择 **Deploy from a branch**，分支选 `main`（或 `master`），目录选 `/ (root)`
4. 保存后等待 1~2 分钟，即可通过 `https://<你的用户名>.github.io/coffee-wiki/` 访问

> 本站无任何外部依赖（无 CDN、无网络字体、无外部图片），GitHub Pages 可直接托管。

## 添加 / 修改词条

编辑 `assets/js/data.js`，在 `ENTRIES` 数组中追加对象即可：

```js
{
  id: "my-entry",        // 唯一英文 id，用作路由
  cat: "brew",           // 所属分类 id（见 CATEGORIES）
  title: "词条标题",
  summary: "一两句话摘要",
  featured: true,        // 可选：是否出现在首页精选
  body: [
    "第一段正文……",
    "第二段正文……"
  ]
}
```

注意：正文请使用中文弯引号“”而非 ASCII 双引号，以免破坏 JS 字符串。
